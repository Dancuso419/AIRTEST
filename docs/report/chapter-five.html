5.2 Limitations and Challenges

While the AIRTEST project yielded valuable empirical data, four technical limitations must be acknowledged:

  • Host Computation Limits: Due to developer hardware constraints (Intel i7-4702HQ), NS-3 Wi-Fi 6 OFDMA simulation runs incurred a ~9x CPU execution penalty compared to Wi-Fi 5. Consequently, client density was capped at 20 active stations per scenario.
  • Measurement Window Artifacts: Simulation scenarios were executed for a 3.0-second measurement window to maintain tractable run times. While sufficient for steady-state throughput measurement, short window durations slightly inflate initial packet loss percentages during TCP handshake phases.
  • Idealized Propagation Model: Physical propagation relied on the NS-3 `LogDistancePropagationLossModel`. While mathematically robust, it does not fully simulate dynamic body absorption or physical furniture obstruction present in real auditoriums.
  • Scope Restrictions in NS-3 3.42: Certain advanced IEEE 802.11ax features, such as Target Wake Time (TWT) client battery optimization, are not fully implemented in NS-3 3.42 and were excluded from comparative evaluation.

5.3 Future Enhancements

To build upon the foundations established by AIRTEST, several future enhancements are recommended for subsequent research:

  1. Extension to IEEE 802.11be (Wi-Fi 7) Protocols: Incorporate emerging Wi-Fi 7 simulation modules in future NS-3 releases to evaluate Multi-Link Operation (MLO) and 320 MHz channel bonding in high-density auditoriums.
  2. Live SNMP / Syslog Network Integration: Expand the React cockpit dashboard to accept live telemetry streams from physical campus enterprise access points (e.g., Cisco, Aruba) via WebSocket connections alongside simulation datasets.
  3. High-Performance Distributed Simulation: Deploy the NS-3 batch runner on high-performance computing (HPC) clusters to scale client density models from 20 to 500 active stations per auditorium.
  4. 3D Ray-Tracing RF Propagation: Integrate 3D physical ray-tracing engines (such as Remcom Wireless InSite) into NS-3 to model physical seating tiers, concrete walls, and human body RF absorption accurately.

5.4 Recommendations

Based on the empirical telemetry gathered during the AIRTEST project, the following four actionable recommendations are offered to higher education IT directors and campus network engineers:

  • Prioritize Wi-Fi 6 Upgrades in High-Density Auditoriums: Campus IT departments should prioritize Wi-Fi 6 infrastructure upgrades specifically in large lecture halls and auditoriums. The ~25% airtime reduction achieved by OFDMA solves airtime starvation without requiring additional spectrum licenses.
  • Enforce BSS Coloring in Multi-AP Deployments: Network engineers configuring multi-AP lecture theatre deployments must enable BSS Coloring tags on enterprise controller software to mitigate Overlapping BSS (OBSS) interference.
  • Adopt Airtime-Based Monitoring: University NOCs should move away from monitoring simple RSSI or peak throughput metrics and instead adopt airtime utilization and MAC contention latency as primary Key Performance Indicators (KPIs).
  • Avoid Unnecessary Channel Bonding: In high-density 3-AP lecture hall setups, IT teams should deploy 20 MHz or 40 MHz channels rather than 80 MHz channels to maximize the number of non-overlapping channels available and eliminate co-channel interference.

5.5 Summary

The AIRTEST project has delivered a complete, quantitative, and visually compelling performance evaluation framework comparing IEEE 802.11ac (Wi-Fi 5) and IEEE 802.11ax (Wi-Fi 6) protocols in dense university lecture theatres. Through deterministic NS-3 3.42 discrete-event simulation, automated Python parsing, and an innovative React 19 aircraft cockpit instrument dashboard, the project demonstrated that Wi-Fi 6 delivers substantial spectral efficiency advantages. By reducing medium airtime occupancy by approximately 25% while maintaining throughput stability, Wi-Fi 6 resolves dense campus contention bottlenecks, providing a clear return on investment for university technology upgrades.

Appendix C: Cockpit UI Gauge Schematic Specifications

The SVG dual-needle gauge components are constructed on a 200 × 120 coordinate box. Needle rotation angles (\(\theta\)) are calculated using linear interpolation from parameter min/max bounds:

$$\theta = \left( \frac{\text{Value} - \text{Min}}{\text{Max} - \text{Min}} \right) \times 180^\circ - 90^\circ$$
